# Checkpoint-01---Analise-de-Dados-de-Energia
# Análise de Dados — Soluções em Energias Renováveis e Sustentáveis

## Atividades

### Aulas 03 e 04

O notebook `CP1_2sm_Sers.ipynb` contém os exercícios de análise de dados desenvolvidos durante as Aulas 03 e 04.

Foram utilizados diferentes conjuntos de dados relacionados ao setor de energia, realizando atividades de:

* leitura e organização de dados;
* criação e manipulação de DataFrames;
* análise estatística;
* filtros e recortes de dados;
* cálculo de indicadores;
* análise de consumo de energia.

### Desafio Final

O notebook `Desafio_Final_Energia_ONS_API_Final(2).ipynb` apresenta uma análise de dados de carga elétrica obtidos por meio da API pública do Operador Nacional do Sistema Elétrico (ONS).

A análise contempla:

* consulta à API;
* criação e inspeção de DataFrame;
* organização dos dados;
* tratamento de valores ausentes;
* cálculo de indicadores estatísticos;
* identificação de períodos de alta demanda;
* criação de um segundo critério de análise;
* criação de gráficos;
* síntese dos resultados;
* geração e validação de relatório técnico.

A análise do Desafio Final utiliza inicialmente a área de carga **SP — São Paulo**, no período de **01/08/2025 a 07/08/2025**.
